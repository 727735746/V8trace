# 分享副本 / 字段设置

这是可选的独立派生副本，不是原始完整采集、可直接重放的案例或全内容处理保证。两种版本使用相同服务，不需要 Professional 通道。

## 显式流程

在采集配置中载入已完成采集，再选择「分享副本 / 字段设置」。来源也可改为原始导出目录（根部含 `export.summary.json`）。填写新目录与字段设置，点击「预览字段 / 覆盖」，核对规则、实际命中次数、路径样本、省略及覆盖边界；最后明确「确认创建分享副本」。任何输入修改都使 UI 的确认按钮失效；内核再次计算来源文件 / 规则绑定，不接受过期预览。

```json
{
  "protocol": "v8trace/share-fields/1",
  "copyOpaque": false,
  "rules": [
    {"field": "authorization", "action": "replace", "value": "[字段已处理]"},
    {"field": "password", "action": "remove"}
  ]
}
```

规则仅匹配 JSON 对象成员名，ASCII 大小写归一，递归处理数组里的对象；不执行表达式、正则、脚本或 VM 语义。命中整个对象值时处理整个值，不把其内部字段另算作命中。预览显示字段名 / 路径和计数，不显示原字段值。文件名、原目录路径与哈希等来源清单元数据不参与规则处理，也应在分享前核对。

副本 JSON 统一序列化为紧凑 UTF-8 + LF，不保留原排版；整数须落在 int64 / uint64，浮点沿用内核 double 语义。超范围整数整项省略，不静默舍入；重复成员名继续由内核解析器拒绝。根 summary 的派生标记在字段规则之后强制写入，此额外变更也列在预览覆盖范围中。CLI 字段设置文件上限 64 KiB。

## 真实覆盖边界

- JSON 单文件、JSONL 单条记录最多 1 MiB、递归深度 128；JSONL 文件本身可大于此值，按记录流式处理。文件树最多 20000 项、相对路径总字节最多 4 MiB。预览最多 100 个命中路径、20 个文件样本；超出 4096 字节的单个路径以显式显示边界标记替代，计数仍保留。最终清单保留每个文件的处置和原始 / 副本哈希。
- 格式错误、超出记录/深度覆盖的 JSON 文件整项省略，不把未处理的剩余内容静默传出。
- 默认省略二进制、媒体、源码正文及其他非 JSON 文件。明确 `copyOpaque=true` 时只按原字节复制，清单标为 `copied-verbatim-unprocessed`，不修改二进制，也不声称其内部字段已处理。
- 不解码字符串中的 JSON、URL、压缩/加密内容，不按 `name/value` 请求头对推断字段含义，不跟随 JSON 引用字段，不修复或重绑定内容哈希引用。省略的 blob 对应引用可能不可用；副本不声称可重放、可执行或已完成算法还原。
- 当前安全路径后端仅支持本地 Windows 盘符路径；其他平台显式报出后端边界。来源与目标各组件拒绝重解析点、父级遍历及替代流。祖先目录持有禁止删除的句柄；选中目录额外限制写入共享，源文件在读取期间禁止写入/删除共享。使用 [CreateFile 重解析语义](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilea) 和 [重解析属性检查](https://learn.microsoft.com/en-us/windows/win32/fileio/reparse-point-operations)，不改系统权限或其他程序。

## 来源与结果

只创建之前不存在的独立目标，不覆盖，不在原目录内创建副本，不写入原采集、原导出或原哈希。文件存放在 `content/`，`share.manifest.json` 记录来源、原始 / 副本 SHA-256、字段设置、预览绑定和处理范围；清单中的哈希是各自字节的身份，不是字段处理证明。原完整性结论不继承为副本完整性；派生 summary 明确 `derived-not-assessed`。

先创建 `share.started.json`。只有全量来源快照再次相符才写完成清单。取消 / 失败保留新目录及 `share.failed.json`，不生成完成清单，也不自动删除任何原文件。失败后的部分文件只用于核对，重新执行请选择另一个新目录。外部程序在验证之后继续改动文件不属于此时点快照；分享前仍需核对清单与实际字节。

## CLI 与测试

```text
v8trace-runtime share-preview --source SOURCE --settings FIELDS.json
v8trace-runtime share-copy --source SOURCE --output NEW_DIRECTORY --settings FIELDS.json --binding PREVIEW_BINDING
```

`sharing-copy` CTest 覆盖嵌套字段、原字节、哈希、大小边界、大 JSONL、显式二进制复制、过期预览、取消及失败保留。`tests/ui_share_copy_tests.ps1` 用实际双版本内核验证预览 → 确认 → 清单、输入失效、已有目录保护及关闭时取消，不运行浏览器或使用真实日志。
