# 配置复用、启动预检与证据索引

本文为 UTF-8 中文。底层为 C++，界面为现有 Windows WinForms；没有新增 Node 运行依赖。新增能力需要同时更新 UI 与 C++ 内核，旧版配套 Chrome 的真实能力另由预检核对。

## 配置 / 启动预检

1. 「读取当前」把当前**已应用**配置放到编辑框；编辑不会自动生效。
2. 「导入替换」用新配置取代原配置；「导入合并」递归合并对象，数组/标量整体替换，`null` 不表示删除。
3. 预览会列出每个改变字段的存在性、值预览和完整值 SHA-256。长值仅在差异窗口限长，完整值仍在编辑框/导出文件中。结构预检通过后才可确认应用；取消不动当前设置。
4. 「导出当前」导出当前已应用配置，而不是尚未确认的编辑稿。原始路径文本、精确字节预算、未知字段和高级字段保留；没有改变的控件不把 MiB 显示值舍入回写。修改某控件只覆盖该字段。高级字段可在 JSON 中显式编辑。
5. 组合预设是用户显式替换采集策略，未呈现高级字段不继承；应用预设前可先导出原配置。仅选择组合不应用，也不启动采集。
6. 「预检当前配置」检查所选协议、Chrome 描述与库文件 hash、依赖、路径、过滤和预算，**不启动浏览器、不创建日志目录**。点击开始也先执行真实预检，再在启动入口重新校验。预检成功不是网页加载、原生探针或服务端业务验收。

未知字段完整保留并列入报告，但当前内核不执行它们。未来协议/版本会被拒绝，不静默回退或迁移。人可读说明采用中文，机器字段保持协议原名。

```json
{
  "protocol": "v8trace/config/1",
  "schemaVersion": 1,
  "pathBase": "application-working-directory",
  "options": {
    "url": "https://HOST/",
    "chromePath": ".\\chromium\\chrome.exe",
    "output": ".\\logs\\本次新目录",
    "transport": "native",
    "http": true,
    "scripts": true
  }
}
```

也接受原始 options 对象。软件的工作目录是 `V8Trace.exe` 所在目录；CLI 相对路径使用启动 CLI 的当前工作目录，**不是配置文件父目录**。预检同时列原始配置和归一计划，不覆盖导入文件。VM 描述内部源码相对路径仍按描述文件的既有契约处理。

```powershell
.\runtime\v8trace-runtime.exe preflight --config .\采集配置.json
.\runtime\v8trace-runtime.exe config-preview --current .\原配置.json --incoming .\补充.json --mode merge
# 只有显式给 --output 才另存合并配置；目标必须是新文件。
.\runtime\v8trace-runtime.exe config-preview --current .\原配置.json --incoming .\补充.json --mode merge --output .\合并配置.json
```

## 证据索引 / 全文

先载入 `summary.json`，或完成当前采集，再点击「建立 / 重建」。原始采集包只读，索引在自有临时目录中，关闭/重建/正常退出删除；不会向原包塞数据库。进度按源行显示，可停止建索引，已有证据保留。

- 索引包括 `events/*.jsonl`、`catalog/*.jsonl`、根目录 JSONL 和 JSON 报告。类别如 `jscall`、`catalog/scripts`、`report/detail-filter-summary`、`report/native-env-summary`、`gaps`。JSON 报告作为一个可按需读取的源记录。
- 脚本 URL/ID、函数名称/ID、request、录制 window、process/isolate/producer/call 为**元数据精确匹配**，不是 glob，也不是全文模糊搜索。组合多个身份范围避免跨进程同名 ID。没有观察到真实身份的跳转报明边界，不按时间相近猜因果。
- 「跳脚本 / 跳请求 / 跳函数」使用当前行直接观察的字段；脚本/请求可返回多个原始观察。返回集合不是自动确认的唯一归属或异步因果。完整关联结论仍看 `catalog/correlations.jsonl` / `state-correlations.jsonl` 的证据与边界。
- 每页最多 200 行，并设约 2 MiB 列表响应预算；可能少于请求行数，使用返回游标继续，不跳过未显示行。排序为稳定文件/行顺序，不捏造跨线程执行总序。
- 字符串/对象值采用流式元数据投影跳过，列表不先把完整巨大值序列化到内存。每行索引字段至多 512 项、身份值至多 8192 字节、内容引用至多 64 个，超界计入 `indexBoundaryCount`；这仅是索引边界，不删原始值、不改变采集结论。列表显示值也有独立限长。
- 点选日志行后仅读取 64 KiB 原始字节页。「前一段 / 后一段」翻页；UTF-8 显示在字节切分边缘可能出现替换字符，协议 base64 与「完整另存」保留精确原始字节，勿拿界面片段当完整源码。
- 引用列表包含实际 blob 的路径、类型、长度与 hash；「读取引用」先核对路径、长度和 SHA-256，可查看源码、HTTP/WS/IDB/TypedArray 等实际已保存内容。
- 「完整另存」流式输出整个选定行或引用内容到原包之外的新文件，返回长度/hash，不受预览限长影响，不覆写原包/已有文件。
- 建立时记录源文件 SHA-256，查询/读取校验大小、路径和修改时间；源变化要求重建，完整另存还复核源 hash。索引是会话期冻结视图，不是对主动篡改原文件的无限期监测器。

生产端过滤的真实报告位于 `report/detail-filter-summary`；其计数按记录内的 lower-bound/final 语义解释，不凭非零预览推断完整命中。原生环境有独立 `envFilter` 与生产者报告，JSCall/Native 范围不约束 HTTP、源码、Opcode、DrumBrake 或状态专项。

CLI 适合单次检索；每次命令重建自己的临时索引。超大包多轮分页建议使用 UI/Worker 的会话索引，避免重复扫描。

## 白屏 / 开销对照

`nativeTimeline=true` 现在同时记录 Chromium 已有的 `loading` / `devtools.timeline` 加载绘制事件，保留 frame/navigation 身份和原始时间戳，非 CDP 也适用。HTTP 返回不是已经绘制的证明；某个 iframe 的 FCP 也不自动等于主页面成功。没有观测到绘制时保留未观测事实，不反推唯一原因。

高级配置可显式设置 `interpretOnly=true`：只关闭 JS 的 Sparkplug/Maglev/TurboFan 与延迟源码位置，不自动开启逐次日志，不把 WASM 设为 jitless。此项用于“普通基线 / 纯解释基线 / 调用结构 / 目标完整值”的同动作对照，避免把详细插装开销一律归因于关闭 JIT。它不是新增采集通道，目前在 JSON 配置中编辑；导入、导出、预检均保留，应用组合会像其他未呈现高级策略一样重置。

`tests/complex_page_probe.py` 保留每轮真实原包、精确配置、已观察脚本范围、HTTP 结果、绘制标记和进程树内存采样。内存采样不减少原始日志；其峰值是采样下界。站点失败、无匹配、partial 和无绘制均留在结果中，不据此自动宣称修复、完整业务复现或单一因果。

```powershell
.\runtime\v8trace-runtime.exe query --capture .\logs\本次目录 --script 7 --window 2 --limit 100
.\runtime\v8trace-runtime.exe query --capture .\logs\本次目录 --category report/detail-filter-summary
```

## 新专项组合

原有 13 个组合 ID 保留，新增 7 个：

| ID | 选择时机 |
| --- | --- |
| `env-native-probes` | 原生环境缺失/接口/变更/库存补证，不安装 JS wrapper |
| `closure-target` | 已有具体调用范围，需要 Context 分配的词法绑定 |
| `session-state` | Cookie / CookieStore / Storage 会话状态 |
| `websocket-state` | 双向解码内容、分片和连接边界 |
| `indexeddb-state` | request/transaction/cursor 与序列化值 |
| `wasm-modules` | 完整编译输入/模块字节，不强制 DrumBrake |
| `large-log-spool` | 基线叠加持续无损封块；TCP 接收端另由用户填写 |

已确认 VM 点位需独立载入双哈希描述，保持在专门配置页，组合不猜描述或自动激活。新模板说明这些通道、完整 gap 明细、持续搬运/最终提交、索引预览和实际复现边界。案例定位仍是日志采集；补环境路线是本地 V8 跑通关键 JS 后纯协议，最终交付禁止浏览器自动化及兜底。
