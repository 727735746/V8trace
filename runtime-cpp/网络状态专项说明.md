# 网络与状态专项采集

## 会话与进程范围

Blink/net 状态钩子在 Browser、Renderer 和 NetworkService 中采集；解压、GPU 等没有这些钩子的服务不注册状态会话。
WASM 模块与 VM 探针由 V8 辅助家族独立验证。未选中 Blink 状态通道时，不要求无关家族的结束回执；
读取旧日志时，其空标记保存在 `native-state-unselected-sessions.jsonl`，不伪造结束，也不计入所选家族的成功回执。
所选会话缺失开始/结束、实际事件越界或生产者计数不一致，仍记录真实缺口。

编码：UTF-8。四个独立选项默认关闭，CDP / 原生模式都要求新版定制 Chromium；CDP 在这里仅负责驱动和传输，不使用页面包装函数兜底。

|选项|输出事件|实际范围|
|---|---|---|
|`webSocket`|`events/websocket.jsonl`|Renderer 解码后的文本/二进制、Blob 读取结果、接收分块、连接/握手/关闭/错误；不是 TLS 字节或 masked wire frame|
|`indexedDB`|`events/indexeddb.jsonl`|API 入口/异常、事务、请求、键/范围、游标、已有序列化数据；记录压缩前写入和实际物化结果|
|`cookies`|`events/cookie.jsonl`|Document.cookie、CookieStore 限制后端读写结果（含 Worker）、原生 Cookie 存储变更；不是完整初始 Cookie 库|
|`storage`|`events/storage.jsonl`|Storage 读写/删除/清空/枚举及跨窗口通知；命名空间声明为实际 context view|

## 原始值与大值

短值保留完整 base64，长值由生产端逐个 32 KiB 分片输出，再使用磁盘 SQLite 索引流式重组。UTF-16LE 保存 null、空字符串、NUL、孤立代理项；二进制不经过文字转码。`byte-reference` 的 blob、长度与 SHA-256 可校验。文件系统传输句柄以及外部 Blob 内容若尚未读到，会写入关键缺口，不用句柄数量冒充内容。

`native-state-summary.json`、`native-state-sessions.jsonl`、`native-state-producers.jsonl` 记录会话和生产端计数，检查中间序号、尾部、最终排空、缺失分片及孤立分片。采集预算、异常或中途停止造成的缺口均进入完整 `gaps.jsonl`。只清理本次拥有的临时重组目录。

## 身份关联

`catalog/state-correlations.jsonl` 仅依据运行时实际共享的 call / 原生操作 / request / transaction / connection / cursor / value ID。作用域包含进程和录制窗口。Native wrapper ID 不冒充底层网络连接 ID。没有实际 ID、调用被过滤或调用在窗口之外时输出 `unresolved`；时间邻近不用于证明因果。

暂停不冻结网页，也不补录暂停区间。跨窗口异步结果可能只有结果端，标为窗口边界。开启详细 JSCall/Native 后才有相应调用入口可关联；专项通道自身不强制关闭 JIT。

## 验收边界

C++ 夹具验证协议、完整字节、乱序、暂停窗口、缺块、计数、共享身份和导出。固定 Chromium 的影子语法检查验证真实头文件与编译参数。以上均不等于新 Chromium 已链接、真实页面已验收；最终发行需另外通过原生夹具与完整浏览器回归。
