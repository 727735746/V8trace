# 原生环境取证

这组开关独立于旧 Env Hook，默认全部关闭。只采集证据，不自动实现补环境，不调用浏览器代算。

| 配置项 | 内容 |
| --- | --- |
| `envAbsentProbe` | 宿主属性读取与缺失候选；`undefined` 和真实缺失分开表达 |
| `envInterfaceProbe` | 读取、`in`、`hasOwnProperty`、`Reflect.has` 及属性描述符查询 |
| `envHostMutation` | 解释器中的宿主写入、定义、删除，以及原生定义与原型设置 |
| `envInventory` | 每个已观察 realm、每个录制窗口的全局原始命名属性、已实例化接口的静态属性和原型 |

UI 的“原生环境取证”页提供四个勾选项、独立脚本白名单/黑名单、未知来源处理及库存预算。脚本规则与 JSCall/Native 调用过滤互不影响。文件名规则如 `target.js`，URL 规则如 `https://example.test/*.js*`；支持 `*`、`?`。指定白名单时 CLI 默认排除未知来源，UI 按其明确选择执行。

为覆盖 IC 缓存命中，启用任何原生环境开关会关闭 Sparkplug、Maglev、TurboFan，并使用 Ignition。运行成本高于仅 HTTP/源码基线；不要默认对整个复杂网站全量开启。它不会安装 JavaScript 函数包装器，方法身份保持原样。

## 输出

- `events/env.jsonl`：逐条完整操作，包括前后值、原始时间、进程/线程、isolate、弱句柄维护的 realm ID、GC 世代、来源、操作 ID 和生产者序号。
- `catalog/env-inventory.jsonl`：原始存储库存。
- `native-env-producers.jsonl`：生产者最终计数。
- `native-env-summary.json`：配置、数量、库存范围和边界。
- `gaps.jsonl`：序号缺失、尾部缺失、配置不匹配、未完成操作、库存预算等完整缺口明细。

库存属性预算默认 65536，可用 `envInventoryProperties` 设置 1 到 1048576。达到预算明确记为 `partial-budget`，不会宣称完整库存。库存只读取原始命名存储，不执行 getter、Proxy、惰性构造器或虚拟属性枚举，不展开所有元素。对象值仍遵循已有快照开关；地址仅代表观察时地址，realm ID 才使用弱上下文句柄维护，二者不可混用。

原生查询的布尔结果和描述符是真实查询结果。普通读取另记录操作前原始原型链状态：原始链可判定、动态宿主未知、索引存储未知、Proxy 未知、键转换未知等。动态宿主返回 `undefined` 不证明属性缺失。super 读取保留独立查找边界。异常中断与窗口末尾未完成操作保留，不补写推测返回值。暂停期间不补录。

原生插装与宿主解码必须匹配 `v8trace/env/1` 和 `v8trace/env-stats/1`。启动前验证 Chromium 身份、补丁哈希及所选特性；旧版浏览器会明确报版本不匹配，不偷偷换成 CDP 或页面 Hook。

## 验证边界

C++ 协议测试和固定版本 V8 影子语法检查各自独立。完整 Chromium、iframe/Worker、GC/重入/异常的实际运行验收属于最终发布门槛；语法通过不代表这些运行场景已通过。交接导出包含环境日志、库存和摘要，`completeEnvironmentModel` 始终为 false。

## 本轮真实执行补修

新后端描述包含 `envBuiltinProtocol=v8trace/env-builtin/1`；采集器预检会拒绝缺少该能力的旧环境探针后端，旧日志仍可按原格式导入。Object/Reflect 的部分查询走 Torque/CSA 快路径，现按真实 builtin_id 捕获直接解释调用的 `Reflect.has`、`Object.hasOwn`、`Object.getOwnPropertyDescriptor`、`Reflect.getOwnPropertyDescriptor`。支持固定参数、别名调用与普通寄存器参数列表；只观察原始目标/键与真实结果，不重复键转换，不调用 getter，不改方法身份。这里的目标/键不是“所有 Native 实参”选项的替代，额外参数数量仍明确记录。

解释器调用常尾分派而无普通指令 exit。记录在同一栈帧的已确认正常延续点读取真实 accumulator，允许引擎 ShortStar 快路径；出现异常或延续点不确定时保留中断边界，不猜返回值。通过 call/apply/spread 或其他引擎内部转发的快路径不自动推导，保留实际命中的 C++ 查询/解释读写与边界。

所有开启原生追踪的 Chrome 模式均预留 8 MiB 生产者共享内存；开发 d8 同样设置 hint。它不是日志截断上限，也不是无限记录保证。Perfetto 的数组式 buffer 丢包、sequence packet loss 和增量状态失效均参与完整性判定；实际丢包保留关键缺口，而不是报完整。库存与源值继续完整输出，显式预算按原说明处理。
