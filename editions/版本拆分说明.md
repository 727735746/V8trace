“补环境组合完整”指证据链与原始选中值保持完整，不是默认勾满所有高开销选项。
`env-protocol` 保持低开销初探；`env-target-detail` 在填写具体目标脚本后，记录目标 JSCall / Native 完整值。两者都不替用户执行本地业务复现，亦不引入浏览器自动化兜底。

## 实际边界

编译参数：`V8TRACE_EDITION=community|professional`。完整内部源码默认 Professional；公开社区源包缺少专业目录时默认 Community。修改配置、`runtime/edition.json`、UI 控件或场景 JSON 不改变编译身份。

`opcode`、`wasm`、`vmpProbe`、`httpRootTrace`、`domTrace`、`cryptoTrace` 是专业采集选项。社区版预检、配置导入、CLI 与 Worker 均拒绝启用，并列明字段；不静默退回较少日志的配置。后两个是高级根链检查点，不代表社区基础 DOM/API 观察被移除。

社区 MCP 保留 11 个基础工具；专业版保留 16 个，包括根链及请求路径逐函数分析。两版日志 schema 共享；社区基础搜索可以原样读取专业日志。完整性缺口仍如实报告，不因版本而改写 `partial` / `pending`。

共有的磁盘、时长、对象快照和队列预算仍是显式运行边界，两版相同。社区版没有商业日志截断、随机丢记录、额外降速或激活服务器。

浏览器描述与软件必须配对。分版前的完整浏览器按 Professional 处理，不当作 Community。当前正在运行的完整 Chromium 构建继续，原生主补丁和活动源码树保持冻结。社区浏览器需独立补丁、实际编译与原生验收；host 编译通过不等于此门槛已经通过。

## 源码及发行规则

- `runtime-cpp`：共享采集、读取、基础索引、搜索、TCP 和版本边界。
- `professional/runtime`：独有高级分析及 VM 探针实现，仅链接进专业版。
- `editions/community/LICENSE`、`NOTICE`：社区 Apache-2.0 与归属说明。此许可覆盖社区发行中属于 Alcohol 的相应组件；Chromium、V8 及其他第三方仍保留各自许可。
- 专业软件发行包只分发运行文件和必要许可/说明；完整专业源码、原生实现补丁、调试证据及回滚快照仅在内部保存，不嵌入对外闭源软件包。
- 社区源码采用显式允许清单，不直接公开整个内部工作区、`native`、`dist` 或内部源码快照。独立社区 native 链尚未验收前，不生成标为正式可公开的完整源包。
- 分版只作用于后续发行；如历史源码已按开源许可公开，历史授权及第三方通知继续保留，不改写历史标签或已发资产。

官方许可正文：[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0)。Chromium 原有许可见其源码 `LICENSE` 及相应第三方目录。

## 编译及验证

在 x64 Native Tools PowerShell 中运行，输出与缓存分开：

```powershell
.\build-cpp.ps1 -Edition community -BuildRoot G:\v8-trace-build\community-host -OutputPath .\dist\V8Trace-Community -Jobs 1
.\build-cpp.ps1 -Edition professional -BuildRoot G:\v8-trace-build\professional-host -OutputPath .\dist\V8Trace-Professional -Jobs 1
```

以上省略 `-NativeChromePath` 时是 host-only 包，不伪称包含浏览器。提供浏览器时，打包程序先校验真实二进制哈希和版本身份；社区包拒绝旧完整专业浏览器。

双版本主机回归：

```powershell
.\editions\verify-runtime.ps1 -BuildRoot G:\v8-trace-build\edition-tests -Jobs 1
```

可用 `-DependencyRoot` 指向已有 CMake 构建根来复用依赖源码；不复制伪造目标文件或构建成功记录。验证回执中的 `nativeBrowserValidated=false` 是明确的剩余门槛。

主机构建现会先检查资源、路径及输出所有者，并以独占 lease 保护缓存；默认 job 为 1。新批次用 `-PackageBatchId` 与 UI / runtime / Chromium 版本分开记录。输入、依赖、实际 JUnit 和组装文件分别固定到外置不可覆盖绑定；参数 `-WorkspacePlan` 可消费已核验的独立空工作区计划，不迁移当前原生树。详见 [产物绑定与工作区说明](产物绑定与工作区说明.md)。

## 验收与回滚

专业版必须通过原有完整回归；社区版额外核验两种补环境预设、完整选中值、同一运行预算、专业选项负例、配置不升级版本、浏览器配对及基础 MCP。双 UI 从实际 Worker 能力协商，不只读取外部标签。

只在真实配套浏览器及软件门槛全部完成后晋升本地旧入口；此前保持 R7 与用户配置/日志原样，所有本地候选分目录存放。当前任务不触发远端发布或签名。
