社区版软件与定制 Chromium 编译指令（UTF-8 中文，作者 Alcohol）

在配置好 Visual Studio C++、Windows SDK、Python 3.10+、PowerShell 7、depot_tools 的 Windows x64 开发者终端执行。
先准备 native/community-source.json 固定的完整 Chromium/V8/Perfetto 源码及依赖，再执行：

python -B .\native\build_community_chrome.py --checkout G:\chromium-community\src --out-name V8TraceCommunity --evidence G:\chromium-community\build-evidence --jobs 1

该入口执行独立社区补丁应用、GN、构建图同步、链接器单线程保护、实际 Ninja 编译和原生身份/运行文件清单生成。
媒体配置包含 H264/AAC、Chrome FFmpeg、OpenH264、FFmpeg 和 libvpx；编译成功不计作实际播放/编码通过。

随后构建软件并按运行清单加入配套浏览器：
python -B .\editions\stage-native-runtime.py --source G:\chromium-community\src\out\V8TraceCommunity --output F:\native-runtime-community --edition community
.\build.ps1 -Edition community -NativeChromePath F:\native-runtime-community\chrome.exe -BuildRoot .\.cache\community -OutputPath .\dist\V8Trace-Community -Jobs 1

staging 只复制描述文件绑定的完整运行清单，不复制 GN 对象/缓存，不创建硬链接；先检查容量与活动构建所有者，再创建全新目录。复制成功不代表原生或媒体运行通过。

媒体合成样本和采集期播放/编码测试：
python -B .\native\generate_media_fixtures.py --ffmpeg C:\tools\ffmpeg.exe --output G:\media-fixtures
python -B .\native\media_browser.py --runtime .\dist\V8Trace-Community\runtime\v8trace-runtime.exe --assets .\dist\V8Trace-Community\app\v8-trace --chrome .\dist\V8Trace-Community\chromium\chrome.exe --edition community --headful --fixtures G:\media-fixtures --evidence G:\media-acceptance

请使用全新输出及证据目录；阶段支持 apply/verify/configure/build/package。专业生产/分析实现不在社区源码中。
完整解压后运行 V8Trace.exe；运行不需要 Node.js。源码和构建缓存不放入软件发行包。
